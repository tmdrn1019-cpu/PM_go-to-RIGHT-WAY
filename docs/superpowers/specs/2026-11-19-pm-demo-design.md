# 동적 PM 주차존 첫 구현

## 기준과 범위
사용자가 구현 기준으로 지정한 `AGENTS.md`와 `아이디어계획.md`를 따른다. 첫 결과는 로컬에서 실행하는 운영자용 웹 앱이다. 엔진·시간별 수용량·잔여 기기·시민 이동 미션·경보를 하나의 흐름으로 확인한다.

## 구현 방식
엔진만 제공하면 지도와 이동 흐름을 검증하기 어렵고, 실제 운영사 연동은 자격 증명과 장치 사양이 없다. 따라서 React/Vite/Astryx 화면, Express API, Node 내장 SQLite로 시연 데이터를 보존하는 방식을 구현자의 기본 선택으로 사용한다. 운영사 동작과 사진 AI 판정은 명시적인 모의 장치로 제공한다. 현재 작업은 로컬 코드 구현이며 외부 배포·업로드는 포함하지 않는다.

## 동작
- 합성 후보지의 좌표·배치별 유효폭·15분 보행량·시간표를 사용한다. OpenStreetMap 배경 지도와 동등한 기능의 목록을 제공한다. 후보지와 이동선은 가상 자료임을 표시한다.
- LOS 참고 프로필은 2022 보행업무편람에 수록된 보도 보행류율 A≤20, B≤32, C≤46, D≤70, E≤106 인/분/m이다. 최신 2026 도로용량편람·현장 적용성 검토가 끝난 기준으로 주장하지 않는다. 프로필 누락 시 판정 불가다.
- 배치별 유효폭 2m 조건을 적용하고 A~C 개방, D 축소, E~F 폐쇄로 계산한다. 현장 측정 배치표가 없는 곳에는 임의로 대수를 생성하지 않는다. 현재 주차 대수와 권장 수용량을 따로 표시한다.
- 한국 시간의 일일 운영시간표와 자정 통과를 처리한다. 폐쇄 예고 구간에서는 해당 존의 예고 정책으로 수용량을 줄인다.
- 초과·폐쇄 존에 정상 반납된 기기를 열린 존으로 이동한다. 기기 중복 수락과 목적지 정원 초과를 막고, 목적지 정원을 예약한다. 잠금 해제 실패 시 미션을 시작하지 않는다.
- 시연 정책: 최근 이동 제외 120분, 하루 3회, 완료당 1,500 시연 포인트, 제한시간 20분, 경로 허용 폭 50m, 위치 오차 허용 30m, 위치 유효기간 120초. 확정 운영 정책이 아니며 화면에서 확인 가능하다.
- 위치는 시뮬레이터로 입력한다. 경로 이탈·시간 초과 시 모의 경보·알림을 한 번 기록한다. 위치 누락·지연은 이탈과 구분한다. 완료·취소 이후에는 경보를 생성하지 않는다.
- 사진은 브라우저 메모리에서 미리보기만 한다. 외부 전송·저장은 하지 않는다. 서버의 모의 판정 결과 승인/거절/판별 불가로 흐름을 검증한다. 실제 AI 정주차 검증은 미연동이다.
- 완료는 도착 위치·시간·목적지 상태·모의 판정을 서버에서 검사하고 주차 위치 및 포인트를 한 번만 갱신한다. 취소·만료·실패에는 지급하지 않는다.

## 구조와 검증
`server/engine.mjs`: 순수 판정/시간/거리 계산. `server/simulation.mjs`: 미션과 모의 장치 상태 전이. `server/store.mjs`: SQLite 트랜잭션. `server/app.mjs`: 검증된 로컬 HTTP API. `src/`: Astryx 앱과 Leaflet 지도.

Node 내장 테스트 러너로 경계·오류·동시 요청·영속성을 검사한다. 빌드와 Astryx doctor, 실제 브라우저에서 시나리오·모바일 레이아웃을 확인한다. 서버는 127.0.0.1에 바인딩하고 변경 요청의 Origin 및 전용 헤더를 검사한다. 이 앱은 단일 시연 사용자용이며 실제 서비스의 인증·운영사 연동을 제공하지 않는다.
