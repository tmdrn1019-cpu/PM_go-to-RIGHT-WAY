# 모바일 시연: 끌고 이동하는 킥보드 표시 (짧은 설계)

## 의도
`/mobile` 시연에서 미션을 시작하면 킥보드 표식이 사라지고, "도착했어요"를 누르면 목적지로 바로 순간이동한다. 사용자(2026-11-20)는 킥보드가 끌려가는 모습을 지도에서 보고 싶어 한다.

## 접근 방식
- A. 화면 애니메이션만 보여 주고, 도착 좌표는 한 번만 보낸다. 서버 기록과 화면이 어긋난다.
- **B. 경로 위 중간 위치를 서버에 차례로 보내고, 표식은 서버가 받은 위치 사이를 움직인다 (사용자 선택).**

## 설계
- 미션 중에는 그 킥보드 표식을 계속 보인다(선택 표식 스타일, "끌고 이동 중 · 시연" 툴팁). 다른 킥보드는 지금처럼 숨긴다.
- "도착했어요" 대신 "끌고 이동 시작(시연)" 버튼을 둔다. 누르면 경로의 25%·50%·75%·100% 지점을 차례로 서버에 보낸다.
  - 각 위치: 기존 `position` 명령, 정확도 8m, 관측 시각은 시연 시각.
  - 서버가 받은 뒤에만 표식을 그 지점까지 약 1.2초 동안 움직인다. 서버가 거절하면 멈추고 오류를 보인다.
- 움직임 줄이기(`prefers-reduced-motion`) 설정이면 애니메이션 없이 지점으로 바로 옮긴다.
- 진행은 "이동 중 n/4" 문구로도 알린다. 걷는 동안에는 다른 버튼을 막는다.
- 서버 규칙(경로 이탈 경보, 도착 판정, 완료 검증)은 바꾸지 않는다. 화면 문구는 모의 이동임을 유지한다.

## 범위 밖
실제 휴대폰 GPS 추적(`watchPosition`)은 넣지 않는다. 시연 킥보드가 관악구에만 있기 때문이다.
