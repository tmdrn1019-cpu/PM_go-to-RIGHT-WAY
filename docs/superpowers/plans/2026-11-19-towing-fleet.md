# Towing and fleet integration

사용자가 견인 이력으로 분석구역을 설정하도록 변경하고 TAGO 키를 제공했다. 기존 실서비스 설계의 데이터 연결 범위에서 구현한다.

- 실제 `aiTbAutoKickboard` 2025년 신고 이력을 날짜별로 수집하고 관악구의 조치 완료 이력을 주소별 집계한다. 합성 자료·현재 법적 금지경계로 바꾸지 않는다. 조회 실패/페이지 누락에는 완성 파일을 교체하지 않는다.
- 주소 좌표가 없으므로 좌표 변환 키가 준비되기 전에는 주소별 분석구역을 제공하고 지도 폴리곤을 생성하지 않는다. 해당 의존성을 사용자에게 질문했다.
- TAGO의 서울 요청이 세종 자료를 반환하는 실제 동작을 확인했다. 응답 지역을 검증하고 지원 목록으로 조회를 제한한다. 서울 미지원과 기기 0대를 구분한다.
- TAGO 위치는 조회 가능한 지역을 사용자가 고른 경우에만 제공한다. 기기 원관측 시각은 응답에 없어 수집 시각과 구분한다. 기기 제어는 추가하지 않는다.
- 키는 `.env.local`에만 보관. 새 의존성 없음. 실제 파일은 `data/`에 보관한다.

- 서울시 견인 API 정상, 총 283998행. 주소는 있고 좌표는 없음.
- 실제 오프셋 페이지 수집에서 같은 번호·같은 내용의 행이 페이지 사이 중복 반환됨을 확인했다(진단 시 42,000행 중 1,746회 반복, 내용 충돌 0). 불완전한 결과는 게시하지 않았다.
