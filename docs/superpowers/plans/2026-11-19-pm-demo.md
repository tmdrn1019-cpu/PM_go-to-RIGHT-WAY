# Dynamic PM Demo Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 로컬 웹 앱에서 동적 주차존과 시민 이동 미션·경보의 전체 시연 흐름을 실행한다.
**Architecture:** 순수 엔진을 Express API와 React가 공유한다. 미션 변경은 SQLite 트랜잭션 안에서 처리한다. 지도·사진·기기 제어의 실제 연동과 모의 연동을 구분한다.
**Tech Stack:** Node 24, React, Vite, Astryx, Express 5, Leaflet, node:sqlite, node:test.
**Spec:** `docs/superpowers/specs/2026-11-19-pm-demo-design.md`

## Global Constraints
- 한국어 UI, 영어 식별자. 로컬 실행, 외부 배포·업로드 없음.
- 보도 유효폭 2m 이상, LOS A~C 개방 / D 축소 / E~F 폐쇄.
- 시연 자료·참고 기준·미연동 기능을 화면과 README에서 표시한다.
- 원본 사용자 위치·사진과 자격 증명을 저장하지 않는다.

## Review Focus
- 경계와 유효하지 않은 값: 0 폭·NaN·누락 입력으로 개방하지 않는다.
- 자정과 예고: 전날 시작 구간 및 다음 날 폐쇄를 놓치지 않는다.
- 동시 수락: 목적지 예약을 포함해 정원을 넘기지 않는다.
- 중복 요청: 완료/보상/경보를 중복 적용하지 않는다.
- 오래되거나 부정확한 위치: 정주차 승인이나 이탈 확정에 사용하지 않는다.

- 기본 선택: 기존 AGENTS의 구현 우선순위와 스택 제안을 사용해 이 세션에서 직접 구현한다.

- Task 2 complete: 미션/API 포함 39개 테스트 RED → GREEN. SQLite 트랜잭션과 보존 검증.
- Review: 별도 검토자가 발견한 6개 결함을 각각 재현하는 테스트 추가, 실패 확인 후 수정. 총 45개 통과. 전망 원본 덮어쓰기, 출발 전 중복 배정, 예고 배치 LOS, 폐쇄 후 반납, GPS 출발 오차, 누락/단위 다른 기준표를 수정했다.

- 최종 검사: npm test 45/45, npm run build 성공, astryx doctor --built dist 실패 0/경고 3. 경고는 외부 Figtree 폰트 자동 입증 불가(관련 상위 요약 포함 2개)와 Windows CLI 경로 진단 1개다. npx astryx 실행은 정상이다. Vite에는 약 984kB 초기 JS 청크 경고가 남아 있으며 배포용 분할 최적화는 이번 범위에 포함하지 않았다.
- 개발 중 새 Astryx 의존성을 실시간 최적화할 때 일시적인 React 중복 로딩 오류가 발생했다. 설치 중인 React/DOM은 19.3.1 단일 버전임을 확인했고, 개발 서버 재시작 및 새로고침 후 Collapsible 정상 동작을 확인했다. 최종 빌드 화면에서도 오류가 재현되지 않았다.
- 확인하지 않은 항목: 실제 공공데이터·장치·운영사·사진 AI 및 현장 안전/효과 검증. 모의 동작과 근거 한계는 README와 UI에 표시했다.
