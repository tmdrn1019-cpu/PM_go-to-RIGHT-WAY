# SGIS 견인 분석 위치 구현

사용자 승인 범위: SGIS 공공 API로 기존 관악구 견인 주소별 집계를 지도에 표시하고 서버 환경변수 이름을 안내한다.

1. SGIS 공식 인증·WGS84 주소 검색 계약을 확인하고 정확한 일치만 채택하는 테스트를 작성한다.
2. 서버 전용 인증/검색, 재개 가능한 비공개 좌표 파일 수집 명령, 읽기 전용 API 병합을 구현한다.
3. 기존 Astryx 패널과 Leaflet 지도에 건수 표식·개별/전체 이동·미변환 상태를 연결한다. 운영 존·법적 경계와 구분한다.
4. 환경변수 예시·실행 안내를 갱신하고 테스트·빌드·Astryx 검사·데스크톱/모바일 화면을 검증한다. 키 부재 시 실 API 검증 한계를 기록한다.

새 의존성, 임의 다각형, 자동 개방, 브라우저 키 노출과 공개 요청에 따른 대량 지오코딩은 추가하지 않는다.

## 검증 결과

- `npm test`: 96개 통과. 실 응답의 부번 없는 지번(`jibun_sub_no="null"`)을 재현하는 회귀 검사 포함.
- `npm run build`: 성공. 기존 번들 크기 경고 유지. `npx astryx doctor --built dist`: 19 통과, 3 경고, 실패 0.
- 사용자 키로 실제 인증·주소 변환 완료: 2025년 관악구 견인 4,946건 / 주소 1,352곳 중 대표점 1,313곳, 정확한 일치 확인 필요 39곳, 미변환 0곳. 원자료와 좌표는 비공개 data/에만 보관.
- 실제 Edge 데스크톱·390px 모바일에서 표식·개별/전체 지도 이동·건수 팝업·탭 이탈 시 표식 제거·가로 넘침/JavaScript 오류 없음을 확인. 검증 스크립트와 이미지는 무시되는 `.superpowers/qa/`에 보관.
- 서버 재시작 후 공개 API 조회 성공. `.env.local`과 좌표 파일 직접 요청 404. 저장소 대상 파일·클라이언트 번들·공개 응답에서 SGIS 키 값 미검출.
- 코드 리뷰의 중요 결함 없음. 현장 좌표 정확도와 영업 이용 승낙은 미검증이며 법적 경계·운영 허가를 주장하지 않는다.
