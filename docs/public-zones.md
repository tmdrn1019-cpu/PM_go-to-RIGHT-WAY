# 토지이용 구역 동적 주차존 (공공데이터 기반)

사용자 결정(2026-11-21)으로 앞선 존(견인 다발 지점 31곳, 이어서 보도선 조각)을 모두 대체했다.
- **존 모양:** 운영사 앱의 반납 구역처럼 지도 위 구역(면)으로 그린다. OpenStreetMap의 주거·상업·판매 토지이용 구역(`landuse=residential|commercial|retail`)을 모양 그대로 쓴다. 주로 아파트 단지, 상가, 대형 판매시설 블록이다.
- **동작(사용자 요청 2026-11-21):** 평소에는 존이 없고, 혼잡한 곳·시간에만 축소·폐쇄 존이 생긴다. 지도와 목록에는 지금 축소·폐쇄된 조각만 보인다.
- **크기(같은 요청):** 존이 너무 넓지 않게 토지이용 구역을 100m 격자로 잘라, 실제 경계를 따르는 1ha 이하 조각으로 쓴다.
- **혼잡 기준(사용자 선택 "둘 다"):** 아래 두 판정 중 더 엄격한 쪽을 따른다(`server/public-zones.mjs`의 `evaluateArea`).
  1. 가장 가까운 지하철역(300m 안)의 시간대별 승하차를 서울 전체 역·시간 기준선과 비교한다(`evaluateRelative`).
  2. 150m 안의 2015 보도 조사 지점으로 보행 LOS를 계산한다(`evaluateZone`).
- **자료가 없을 때:** 두 자료가 모두 없는 시간·구역은 **기본 개방**이다. 사용자 정책이며, 화면에 "기본 개방(가정)"으로 표시한다.
- **견인 자료:** 구역 선정에 쓰지 않고 합성 PM 층에만 남는다.
- **지역:** 지도 반응 속도를 위해 동작·관악·서초·강남 4개 구만 쓴다(사용자 선택).

웹 지도(`/service`)는 `GET /api/zones?active=1&at=`로 구역을 시각별로 판정해 빠른 시계로 보여 준다. 모바일(`/mobile`, 사용자 요청 2026-11-21)은 같은 API로 실제 현재 시각의 축소·폐쇄 조각을 그리고, 1분마다와 탭 복귀 시 다시 받는다. 받지 못하면 오래된 존을 남기지 않고 지운다. 시연 미션과 견인 원은 그대로 `/api/demo` 시연 자료다.

## 만드는 방법

```
npm run build:zones -- data/towing-source-12968.jsonl
```

필요한 것은 아래와 같다.
- 서버 환경변수 `SEOUL_OPEN_DATA_KEY`, `SGIS_SERVICE_ID`, `SGIS_SECURITY_KEY`
- `npm run convert:sidewalk`로 만든 `data/sidewalk-2015.json`(Python, `openpyxl`·`pyproj` 필요)
  - 원자료는 비공개 `data/zone-source/` 아래 [조사지점정보 OA-21707](https://data.seoul.go.kr/dataList/OA-21707/F/1/datasetView.do)과 [관찰조사 OA-21705](https://data.seoul.go.kr/dataList/OA-21705/F/1/datasetView.do)이다.
  - 두 데이터셋은 열린데이터광장에서 종료 서비스로 표시되어 있다.
- 견인 JSONL: 합성 PM 층에만 쓴다.

실행할 때 받는 자료:
- 서울시 API: 지정 주차구역(`parkingKickboard`, 회색 P 층), 역 좌표(`subwayStationMaster`), 역별 시간대 승하차(`CardSubwayTime`, 공개된 최근 달)
- OpenStreetMap Overpass(`overpass-api.de`): 4개 구 경계 상자(위도 37.42~37.54, 경도 126.88~127.13) 안의 토지이용 구역
  - 한 번에 받아 `data/osm-areas.json`에 캐시하며, 다시 받으려면 이 파일을 지운다.
  - OSM 자료는 ODbL이며 지도에 OpenStreetMap 출처를 표시한다.
  - 닫힌 way만 쓰고, 멀티폴리곤 relation은 아직 쓰지 않는다.

결과는 비공개 `data/public-zones.json`(또는 `PUBLIC_ZONES_FILE`, `version: 7`)에 원자적으로 쓴다. 옛 v6 파일은 읽지 않으므로 다시 빌드한다.

## 선정

1. OSM 토지이용 구역 중 면적 3,000~2,000,000m²만 쓴다.
2. 각 구역을 서울 고정 100m 격자로 자른다(Sutherland-Hodgman, `gridPieces`). 조각은 구역 경계를 그대로 따르며, 300m² 미만 조각은 뺀다.
3. 조각 중심에서 가장 가까운 2015 조사 지점의 구 코드(id 앞 두 자리: 20 동작, 21 관악, 22 서초, 23 강남)로 구를 정한다.
   - 경계 근처에서는 구가 틀릴 수 있다.
4. 지하철역 300m 안이거나, 쓸 수 있는 2015 조사 지점 150m 안인 조각만 지켜본다. 그 밖의 조각은 닫힐 근거가 없어 존이 되지 않는다.
   - 300m·150m·100m는 가정이다.
5. 같은 구역의 조각이 여럿이면 이름 뒤에 번호(예: `반포르엘아파트 2/5`)를 붙인다.

2026-11-21 결과는 지켜보는 조각 **1,216곳**이다(OSM 구역 1,516개 중).
- 조각 면적: 중앙값 약 3,300m², 최대 1ha
- 역 자료가 있는 조각: 925곳
- 보도 LOS 자료가 있는 조각: 495곳

## 판정 규칙과 값의 출처

| 값 | 출처·가정 |
| --- | --- |
| 모양 | OSM 토지이용 구역 다각형 그대로 |
| 역 기준 | 300m 안의 가장 가까운 역. [지하철 역별 시간대별 승하차](https://data.seoul.go.kr/dataList/OA-12252/S/1/datasetView.do) 월 합계 ÷ 그 달 일수. 서울 모든 역의 운행 시간 역·시간 값 중 상위 5%(2026-10 기준 5,008명) 이상이면 **폐쇄**, 상위 15%(2,745명) 이상이면 **축소**다. 비율은 가정이며, 역 승하차는 주변 보행량의 대리지표다 |
| 보도 기준 | 150m 안의 2015 조사 지점의 시간별 평균 ÷ 4를 15분 값으로 쓰고, 기기 10대 1.2m·5대 0.6m(가정)를 뺀 폭으로 LOS를 매긴다(2022 보행업무편람 A≤20·B≤32·C≤46·D≤70·E≤106 명/분/m). D면 축소, E~F면 폐쇄다. 남는 폭이 2m 미만인 조사 지점은 구역 판정에 쓰지 않는다(좁은 보도 하나로 블록 전체를 계속 닫지 않게). 조사 시간 7~20시 밖에는 쓰지 않는다 |
| 결합 | 쓸 수 있는 판정 중 가장 엄격한 상태(폐쇄 > 축소 > 개방)를 따르고, 정원은 그중 가장 작은 값이다. 판정 근거 화면에 두 판정을 모두 보인다 |
| 수용 대수 | 평소 10대, 축소 5대(가정) |
| 주차 대수 | 운영사 자료가 필요해 `null`이다 |

2026-11-21 결과(조각 1,216곳, 승하차 2026-10)에서 생기는 존 수는 아래와 같다.

| 시각 | 축소 | 폐쇄 |
| --- | --- | --- |
| 3시 | 0 | 0 |
| 8시 | 145 | 188 |
| 12시 | 107 | 73 |
| 18시 | 145 | 204 |
| 22시 | 32 | 67 |

## 지도 표시

- 두 화면 모두 `active=1`로 지금 축소·폐쇄인 조각만 받는다(전체 약 1.9MB → 밤 약 14KB, 18시 약 0.6MB). 응답의 `counts`에 지켜보는 조각·축소·폐쇄 수가 있다. 서버는 결과 파일을 바뀔 때만 다시 읽는다.

- 지금 축소·폐쇄인 조각만 하나의 canvas 층에 다각형으로 그린다. 개방 조각은 그리지 않는다.
- 색과 함께 테두리로도 구분한다: 축소는 주황 긴 점선, 폐쇄는 빨강 짧은 점선이다.
- P 표지판은 선택한 구역에만 단다.
- 테마 색 `light-dark()`는 canvas가 읽지 못해 브라우저가 rgb로 바꾼 값을 쓴다.
- 회색 P(지정 구역)와 합성 PM(견인 주소 30m 가정 위험 표시)은 4개 구만 표시한다.

## 남은 한계

- 토지이용 구역은 아파트 단지·상가 블록이라 보도 자체가 아니다. 반납 허가나 설치 승인이 아니며 현장 확인을 하지 않았다.
- OSM에 구역이 그려지지 않은 곳은 존이 없다.
- 같은 역(300m 안)을 쓰는 조각은 함께 바뀐다.
- 존이 없는 곳이 반납 가능한 곳이라는 뜻은 아니다. 횡단보도·점자블록 등 법규상 금지 위치는 그대로다.
- 격자로 자른 조각의 경계선이 지도에 보인다.
- 2015 보도 자료는 오래됐고 1시간 평균이라 15분 첨두보다 낮다.
- 큰 무명 주거 구역 안에 이름 있는 단지가 따로 그려진 곳은 조각이 겹친다(2026-11-21 빌드 1,216곳 중 8곳).
- 원자료와 결과 파일은 비공개 `data/`에 두고 커밋하지 않는다.
