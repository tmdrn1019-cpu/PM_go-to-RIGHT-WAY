# 견인 다발 지점 옆 동적 주차존 (공공데이터 기반)

사용자 결정(2026-11-20):
- 현장 실측 없이 공공데이터로 존을 확정한다.
- 지역은 서울 전체로 하고, 목적은 **견인이 많이 일어나는 곳의 해소**와 **혼잡이 많은 곳의 동적 운영**이다.
- 공공데이터로는 서울 어디서도 보행 LOS D 이상이 나오지 않았다. 그래서 이 존들은 LOS 대신 **장소별 상대 혼잡** 규칙(`server/engine.mjs`의 `evaluateRelative`)으로 판정한다.
- 이후 사용자 요청에 따라 다음을 해결했다.
  - **주차 허가:** 존을 견인 다발 지점에서 가장 가까운 **서울시 지정 PM 주차구역**으로 옮겼다.
  - **밤 시간 판정 불가, 센서 없는 지점, 같은 센서 공유:** 혼잡도 자료를 S-DoT 센서에서 **가장 가까운 지하철역의 시간대별 승하차**로 바꿨다.

웹 지도(`/service`)는 `GET /api/zones?at=`로 존을 시각별로 판정해 빠른 시계로 보여 준다.

## 만드는 방법

```
npm run build:zones -- data/towing-source-12968.jsonl
```

필요한 것은 서버 환경변수 `SEOUL_OPEN_DATA_KEY`, `SGIS_SERVICE_ID`, `SGIS_SECURITY_KEY`이다. 견인 원본은 `npm run sync:towing`이 남긴 비공개 JSONL이다. 지정 주차구역(`parkingKickboard`), 역 좌표(`subwayStationMaster`), 역별 시간대 승하차(`CardSubwayTime`, 공개된 최근 달)는 실행할 때 서울시 API로 받는다. 좌표는 `data/towing-geocodes.json`과 `data/parking-geocodes.json`에 캐시한다. 결과는 비공개 `data/public-zones.json`(또는 `PUBLIC_ZONES_FILE`, `version: 3`)에 원자적으로 쓴다.

## 선정 과정

1. 2025-01-01~12-31 서울 전체 견인 64,734건을 주소별로 묶고, 상위 150개 주소를 SGIS로 정확 일치 변환한다.
2. 견인이 가장 많은 주소부터, 아직 묶이지 않은 주소 중 반경 300m 안을 하나의 견인 다발 지점으로 묶는다.
3. 각 지점에서 **500m 안의 가장 가까운 서울시 지정 PM 주차구역**을 존으로 삼는다. 지정 구역 329곳 중 251곳의 좌표가 정확 일치했다.
4. 그 지점에서 1km 안의 가장 가까운 지하철역 하루 승하차가 서울 역 중앙값 이상이어야 한다("혼잡이 많은 곳").
5. 견인 건수 순으로 정렬하고, 같은 지정 구역은 한 번만 써서 상위 20곳을 고른다.

2026-11-20 결과(승하차 2026-10 기준)는 20곳이다. 역삼역 8번 출구(견인 478건, 다발 지점 97m, 역삼역 176m)부터 독산역 2번 출구 인근(73건)까지이며, 강남·서초 외에 송파·마포·구로·관악·금천이 포함된다.

## 판정 규칙과 값의 출처

| 값 | 출처·가정 |
| --- | --- |
| 위치·이름 | [서울시 전동킥보드 주차구역 현황](https://data.seoul.go.kr/dataList/OA-21710/S/1/datasetView.do)(서울시 지정) + SGIS 좌표 |
| 경계 | 대표점 중심 6m × 1.2m 동서 방향 직사각형(가정) |
| 수용 대수 | 평소 10대, 축소 시 5대(가정) |
| 혼잡도 | [지하철 역별 시간대별 승하차](https://data.seoul.go.kr/dataList/OA-12252/S/1/datasetView.do) 월 합계 ÷ 그 달 일수(승차+하차, 같은 역 여러 호선 합산). 역 좌표는 `subwayStationMaster`의 호선별 좌표 평균 |
| 판정 | 그 장소의 24시간 승하차 중 상위 10% 시간은 **폐쇄**, 상위 30% 시간은 **축소**(5대), 나머지는 **개방**(10대). 지하철이 다니지 않는 시간은 승하차 0으로 개방 |
| 주차 대수 | 운영사 자료가 필요해 `null`. 화면은 수용 정원만 표시 |

## 남은 한계

- 지하철 승하차는 역 주변 보행량의 대리지표이며 그 보도의 실측이 아니다.
- 출퇴근 정점이 서울 전체에 공통이라 18시 전후에는 대부분의 존이 함께 폐쇄된다. 같은 역을 쓰는 존(예: 삼성역·학동역·봉은사역 인근)은 똑같이 바뀐다.
- 견인 1위 강남구 청담동 77(500건)은 500m 안에 지정 주차구역이 없어 빠졌다.
- 지정 구역은 서울시가 설치한 공간이지만 보도 폭은 따로 확인하지 않았다.
- 상위 150개 주소만 좌표 변환한다.
- 원자료와 결과 파일은 비공개 `data/`에 두고 커밋하지 않는다.
