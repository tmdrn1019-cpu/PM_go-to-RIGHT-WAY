# SGIS 견인 주소 지도 표시

## 설정과 실행

[SGIS 개발지원센터](https://sgis.mods.go.kr/developer/)에서 인증키를 신청하고 서비스 ID와 보안 Key를 발급받습니다. 기존 `.env.local`에 아래 두 항목을 **추가**합니다. 기존 서울시·TAGO 키를 덮어쓰지 마세요.

```dotenv
SGIS_SERVICE_ID=발급받은_서비스_ID
SGIS_SECURITY_KEY=발급받은_보안_Key
```

`VITE_` 접두사는 사용하지 않습니다. 두 값과 AccessToken은 서버에서만 사용하며, 브라우저·응답·저장 파일·로그에 넣지 않습니다. 인증/조회는 SGIS 공식 HTTPS 주소로 요청하며 리다이렉트는 거절합니다.

견인 원자료가 없다면 `npm run sync:towing`으로 먼저 수집합니다. 기존 `data/towing-areas.json`이 있으면 재수집 없이 다음 명령을 실행합니다.

```powershell
npm run geocode:towing
npm start
```

실행 중인 서버는 종료 후 다시 `npm start` 또는 `npm run dev`로 실행합니다. `/service`와 `/mobile`의 **견인 분석** 탭에서 지도 표시·확인 필요·미변환 수와 각 주소의 `지도에서 보기` 버튼을 확인합니다. 전체 보기로 표시 가능한 모든 주소를 다시 볼 수 있습니다. 검색은 주소 목록을 필터링합니다.

키가 없으면 변환 명령은 요청·파일 변경 없이 필요한 변수명을 출력하고 실패합니다. 키를 추가한 뒤 **변환 명령을 별도로 실행해야** 합니다. 웹 조회나 서버 재시작만으로 일괄 변환하지 않습니다.

## 자료와 검증

- 서울시 실제 견인 이력의 **주소별 집계**를 SGIS [WGS84 지오코딩 API](https://sgis.mods.go.kr/developer/html/newOpenApi/api/dataApi/addressBoundary.html)로 변환합니다. 응답의 `x`는 경도, `y`는 위도이며 지도에는 `[위도, 경도]` 순서로 전달합니다.
- 완전 매칭(`matching=0`), 결과 1개, 건물/지번 수준(`addr_type=6`), 서울특별시 관악구, 도로명·건물번호 또는 법정동·지번의 정확한 일치를 모두 확인합니다. 좌표는 유한한 서울 주변 WGS84 범위여야 합니다. 여러 후보·동 중심점·빈 좌표·불완전 주소·산 지번은 자동 채택하지 않습니다.
- 원은 **주소 대표점**이고 크기는 견인 건수에 따른 화면상의 표식입니다. 견인이 실제 발생한 정확한 좌표, 물리적인 영향 반경, 법적 견인/주차 금지 경계가 아닙니다. 현장 허가·운영 주차존 판정에 자동 반영하지 않습니다.
- 결과는 비공개 `data/towing-geocodes.json`에 주소 ID·원문·상태·좌표·조회 시각만 저장합니다. Git 및 정적 파일 제공에서 제외합니다. 견인 원본 파일은 바꾸지 않습니다. API는 현재 주소 ID와 원문이 모두 일치하는 항목만 병합하며, 좌표의 사용 기한은 이 앱의 갱신 정책인 30일입니다.
- 순차 조회 사이 250ms 간격을 두고 25건마다 원자적으로 저장합니다. 요청 실패 시 완료분을 보존하며, 다시 실행하면 유효한 성공 항목을 재사용하고 확인 필요 주소는 재조회합니다. 네트워크·인증·한도 오류를 검색 결과 없음으로 기록하지 않습니다. 동시에 여러 변환 명령을 실행하지 마세요.
- 인증 토큰은 프로세스 메모리에만 보관하고 만료 1분 전 갱신합니다. 공식 문서의 초 단위 설명과 예제의 밀리초 값을 모두 처리하며, 인증 오류 응답은 토큰을 새로 받아 한 번 재시도합니다. 요청은 본문 포함 10초, 최대 2MiB입니다.

## 이용 조건과 검증 범위

[SGIS 이용약관](https://sgis.mods.go.kr/developer/html/newOpenApi/app/rules.html)은 일일 호출 한도와 영리 목적 이용에 대한 사전 허가 조건을 두고 있습니다. **상용 서비스 공개 전 제공기관에 영리 이용 승인을 확인해야 합니다.** 이 구현은 그러한 승인을 대신하지 않습니다.

자동 테스트는 합성 응답으로 주소 정확도·오류·토큰 갱신·저장/재개를 검증합니다. 실제 키의 권한, 실제 주소별 매칭률과 현장 위치 정확도는 키 설정 후 별도로 확인해야 합니다.
